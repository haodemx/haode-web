# HAODE Operating Notes

- Default all HAODE content to Spanish unless the user explicitly asks otherwise.
- Default brand logo is the official HAODE orange mark: orange circle `H`, orange `HAODE` uppercase, and `CALIDAD PROFESIONAL`.
- Do not upload or swap product images unless the user confirmed the exact source material.
- Do not mix membrane/mica photos with screen photos.
- Protect existing prices, product data, image paths, and published URLs when editing the website.
- Avoid unrelated page changes.
- After completing a task, run `git status`, test the relevant pages, commit the change, and push `main`, then report the verification result.
- Every new product launch must include: product name, category, specs, retail price, wholesale price, SEO title, SEO description, and image/video paths.
