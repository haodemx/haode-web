# HAODE Marketing Design

Use this skill for marketing visuals and ad copy.

## Rules

- Default language is Spanish.
- Default branding uses the official HAODE logo.
- Keep the tone commercial and clear for the Mexico mobile-repair wholesale market.
- Suggested sizes:
  - Facebook: `1080x1080`
  - Story/Reels/TikTok: `1080x1920`
- Highlight value terms such as `Calidad Profesional`, `Mayoreo`, `Envíos`, `CDMX`, and `Garantía`.
- Do not invent specs or claims that are not confirmed.
- For comparison graphics, emphasize HAODE quality advantages without false claims.
