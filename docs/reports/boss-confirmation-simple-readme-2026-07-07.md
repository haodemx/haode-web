# 老板版确认表填写说明

文件：`docs/reports/boss-confirmation-simple-2026-07-07.xlsx`

## 怎么填写

1. 老板只需要填写黄色/标记列。
2. 缺价产品：填公开价、批发价、箱价，然后选老板决定。
3. 异常价格：如果现在价格对，就选“保持当前价格”；如果要改，就填新价格并选“改成我填的新价格”。
4. 缺图片：填写真实图片文件名或路径；没有图片就选“需要真实图片”或“暂不上架”。
5. 不确定的产品先选“暂时显示 Consultar”或“暂不上架”。
6. 未确认前不要运行 `publish-products`。

## 三个 sheet

- `缺价产品`：14 行，只处理缺少老板确认价格的产品。
- `异常价格`：7 行，只处理官网/App/Excel 参考价格不一致的重点产品。
- `缺图片`：4 行，只处理缺真实产品图片的问题。

## 本轮边界

本轮只生成老板填写用 Excel 和说明，没有改产品数据、没有改价格、没有替换图片、没有上架产品、没有部署线上。
