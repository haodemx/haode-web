# HAODE 官网发布包瘦身报告

日期：2026-07-24

## 结论

本轮已把官网可发布文件体积从 GitHub Pages 提示的约 1.2GB 降到当前 Git 跟踪文件约 438MB，已低于 500MB 控制线。

## 已做处理

| 项目 | 处理方式 | 数量 | 原体积 | 现体积 | 节省 |
| --- | --- | ---: | ---: | ---: | ---: |
| JPG 商品图 | 保留原路径，压缩尺寸与画质 | 56 | 366.2MB | 13.1MB | 353.1MB |
| PNG 商品图 | 保留原路径，只保留变小结果 | 45 | 285.7MB | 62.3MB | 223.4MB |
| MP4 视频 | 保留原路径，转 H.264、限制尺寸、移除音轨 | 62 | 213.5MB | 82.2MB | 131.2MB |
| 本地报告/截图产物 | 从 Git 发布包移除，本地文件保留 | 69 | 50.6MB | 0MB | 50.6MB |

媒体文件本轮合计节省约 707.7MB；加上本地产物移出发布包，发布包压力已经明显下降。

## 发布包规则

已加入 `.gitignore`：

- `output/`
- `previews/`
- `artifacts/`
- `reports/`

这些目录以后继续作为本地工作产物目录使用，但不再进入 GitHub Pages 发布包。`docs/reports/` 不受影响，仍可保存正式报告。

## 未改范围

- 未改商品价格。
- 未改商品分类。
- 未改 WhatsApp 下单逻辑。
- 未删除线上商品。
- 未替换商品素材路径，只压缩已有文件内容。

## 后续规则

以后新增官网素材建议先压缩再提交：

- 商品主图建议单张控制在 300KB 到 800KB。
- 商品详情图建议单张控制在 1MB 以内。
- 产品短视频建议单条控制在 1MB 到 3MB，特殊展示视频不超过 5MB。
- 本地截图、审计结果、临时预览统一放在 `output/`、`previews/`、`artifacts/`，不要提交进发布包。
