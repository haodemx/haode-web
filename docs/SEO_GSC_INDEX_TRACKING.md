## Instrucciones De Uso

1. Abrir Google Search Console con la propiedad correcta de HAODE.
2. Confirmar que el sitemap activo sea https://haode.com.mx/sitemap.xml.
3. Usar Inspeccion de URL para cada URL prioritaria.
4. Ejecutar Prueba de URL publicada.
5. Si la prueba publicada es correcta, solicitar indexacion.
6. Registrar fecha, estado GSC y notas en la tabla diaria.
7. Repetir la revision diaria hasta que las paginas principales aparezcan como descubiertas o indexadas.

## Guardrails

- No modificar productos.
- No modificar precios.
- No modificar sitemap.xml.
- No modificar robots.txt.
- No crear URL falsas.
- No marcar paginas como indexadas sin evidencia de Google Search Console.
