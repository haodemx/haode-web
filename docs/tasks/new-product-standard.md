# HAODE 新品上架标准流程

## 目标

确保每个新品上架时资料完整、图片真实、价格不被误改，并能正常在 GitHub Pages 展示。

## 必填资料

- 西班牙语标题
- 西班牙语描述
- 分类
- 零售价
- 批发价
- 主图
- 图库图片
- 视频
- SEO title
- SEO description
- SEO keywords
- WhatsApp 下单文案

## 图片规则

1. 未确认产品图片，禁止上传。
2. 不能用其他型号图片代替。
3. Micas 产品不能使用屏幕、OLED、INCELL 或 AMOLED 图片代替。
4. 主图优先使用清晰白底图或真实产品图。
5. 每个产品建议保留 1 张主图和 3 到 5 张图库图。

## 视频规则

1. 视频必须与产品型号一致。
2. 不允许用 Samsung 视频代替 iPhone 视频。
3. 不允许用 iPhone 视频代替 Samsung 视频。
4. 视频必须压缩到 5MB 至 15MB 范围内。
5. 使用 H264 MP4，适配手机端播放。

## 上架检查

- 产品页能打开。
- 分类页能显示。
- 首页推荐如有展示，图片正常。
- WhatsApp 按钮带产品名称。
- 价格与老板提供一致。
- SEO 信息完整。
- 执行 `npm run product-control`，确认新产品没有漏发、缺图、分类错误。

## 输出格式

完成新品上架后必须输出中文报告：

- 产品链接
- 分类链接
- 主图路径
- 图库数量
- 视频数量
- 价格是否确认
- 是否已提交并推送
